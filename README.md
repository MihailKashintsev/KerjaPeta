# KerjaPeta

Учебный проект по географии (техническое направление) — прототип веб-геосервиса, который помогает молодым соискателям работы находить вакансии на заводах промышленного пояса **Джакарта — Бекаси — Караванг — Чикаранг** (Индонезия), строить маршрут до завода, подбирать жильё рядом и находить курсы переподготовки, если не хватает квалификации.

Это статический сайт: чистые HTML/CSS/JS + [Leaflet](https://leafletjs.com/) для карты, без сервера и без сборки.

## Функции

1. Интерактивная карта вакансий с фильтром по отрасли и квалификации.
2. Подбор вакансий по месту проживания (указывается кликом по карте) и навыкам.
3. Оценка маршрута, времени и стоимости поездки до завода.
4. Слой с вариантами жилья рядом с заводами (доступность/безопасность).
5. Курсы переподготовки, если квалификации не хватает для нужной вакансии.

## Как запустить локально

Проект не требует сборки — достаточно открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте в него содержимое этой папки.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту сайт появится по адресу вида `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Важно

Расположение промышленных парков и линии пригородной электрички KRL Cikarang Line приближено к реальной географии. Конкретные вакансии, зарплаты, варианты жилья и курсы переподготовки — иллюстративные примеры для демонстрации идеи сервиса, а не реальные актуальные данные. Расчёт времени и стоимости поездки — приблизительная оценка (в проекте нет подключения к реальным транспортным API).
